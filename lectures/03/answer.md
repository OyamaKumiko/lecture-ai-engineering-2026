# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
    第3回のエージェントでは、「3レベル」について、基礎・実装・発展の3つを正しく回答できた。また、どれか1つに取り組めば宿題完了となることも説明できていた。第1回の素のLLMとは異なり、講座の用語集を検索して回答できる仕組みになっている。ただし、第1回の実際の回答との直接比較はできていない。
- `--trace` で見えたツール呼び出し（ツール名と引数）：
    「LoRAとQLoRAの違いは？」という質問に対し、search_glossaryが2回呼び出された。引数はそれぞれ{'query': 'LoRA'}と{'query': 'QLoRA'}だった。用語を個別に検索し、その結果を使って回答していることが確認できた。
- 1つの質問での LLM 呼び出し回数（`requests`）：
    「LoRAとQLoRAの違いは？」では、requests=2、tool_calls=2だった。1つの質問でも、ツールを使うことでLLMが複数回呼び出されることが分かった。
- 追加したツールと、docstring に書いた説明：
    make_quiz(lecture: int) -> strを追加した。これは指定した講義回の用語集からランダムに1つ選び、「〇〇の意味は？」という確認問題と答えを返すツールである。docstringには「指定した回の用語から1つ選び、確認問題と答えを返す」「復習用の問題を求められたときに使う」と記載した。こちらを実行したところ、make_quiz({'lecture': 2})が呼び出され、「PEFT」の意味を問う確認問題が生成された。また、uv run pytest -qでは15件すべてのテストが成功した。

## 宿題
- 取り組んだレベル：基礎
- やったこと：
  `app/agent.py`の`INSTRUCTIONS`から「用語や講座に固有のことを答える前に、必ずsearch_glossaryで用語集を確認する」という指示を削除した。その後、変更前と同じ「LoRAとQLoRAの違いは？」という質問を`--trace`付きで実行し、ツールの呼び出し方や回答内容を比較した。

- 結果：
  変更前は`search_glossary`が2回呼び出され、引数は`{'query': 'LoRA'}`と`{'query': 'QLoRA'}`だった。変更後も同じツールが同じ引数で2回呼び出されていた。LLMの呼び出し回数も変更前後で`requests=2`と変化がなかった。回答内容についても、どちらもLoRAとQLoRAの違いを正しく説明しており、大きな変化は見られなかった。

- 気づき・疑問：
  `INSTRUCTIONS`から検索を必須とする指示を削除しても、ツールの呼び出し方は変わらなかった。これは`search_glossary`のdocstringにも「答える前に使うこと」と書かれているためだと考えられる。AIの動作はエージェント全体への指示だけでなく、各ツールの説明文にも影響されることが分かった。
